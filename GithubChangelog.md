## Changelog

- new : Auto-Requeue : automatically joins the next game of MW when your game ends (default:off)
- new : SpectatorCompassOverlay : shows a team indicator in the compass when in spectator and also renders the MW skins instead of the player skins
- new : ReplayBookmarksOverlay : replaces the white paper bookmarks with more insightful items and adds team colors
- add option to render player skulls in class selector overlay
- add option to always render the class in lobby hud (default:off)
- add option to always hide the ping in the tablist
- add absorption to mini potion hud
- add option for saving the reported players
- add option for showing the boosting report advice

Use `/mwe` to open the config menu. To install the mod you need to use forge and drop the .jar file in your `.minecraft\mods` folder.
See more information about installation [here](https://github.com/Alexdoru/MegaWallsEnhancements#installation).
